# 手続きレシート デモ

大学・自治体・勤務先から届く情報を、本人に関係するものだけ「毎朝一枚のレシート」にまとめるMVPデモです。

## SwiftUI版（今回のデモ）

`ios/MorningReceipt.xcodeproj` をXcodeで開き、Schemeを `MorningReceipt`、実行先をiPhoneシミュレーターにして実行してください。サーバーや追加パッケージは不要です。iOS 17以降に対応し、Xcode 26.6で検証しています。

詳しい操作方法と実装範囲は [ios/README.md](ios/README.md) にあります。

## Web版の起動（初期デモ）

依存関係はありません。`index.html` をブラウザで開くか、リポジトリ直下で次のように簡易サーバーを起動してください。

```bash
python3 -m http.server 4173
```

その後、`http://localhost:4173` を開きます。

## デモできること

- ACTION / NEWS / CHANCE の3分類と、最大5件のレシート表示
- 記事の「なぜ自分に届いたか」、金額、期限、必要書類、公式出典の確認
- 紙の案内を画像選択で読み取るモックフロー
- 期限・次の行動・必要なものの抽出結果確認
- リマインダー設定と手続き登録の完了フィードバック
